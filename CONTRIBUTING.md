# Contributing Guidelines

We welcome contributions! If you add or modify any user-facing text in the game, please update **all** language files under `data/lang/` so the text is available in every supported language.

Supported languages:

- English (`en.json`)
- Russian (`ru.json`)
- Ukrainian (`uk.json`)

- Provide translations for any new user-facing text in `en.json`, `ru.json`, and `uk.json` in the same pull request. Pull requests lacking translations should not be merged.

Please keep translations in sync to ensure consistent game experience across locales.
